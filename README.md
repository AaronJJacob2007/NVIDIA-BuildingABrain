# Building a Brain in 10 Minutes

A notebook from NVIDIA's introductory deep learning material, kept here as part of my learning. It explores neural networks through the **Building a Brain in 10 Minutes** exercise.

## Open the notebook

- [View the notebook](building-a-brain/BuildingABrain.ipynb) on GitHub.
- [Open in Google Colab](https://colab.research.google.com/github/AaronJJacob2007/NVIDIA-BuildingABrain/blob/main/building-a-brain/BuildingABrain.ipynb).

Run the cells in order and follow the instructions inside the notebook. The notebook is configured for a Python runtime and includes a GPU setting; availability depends on the runtime you choose.
